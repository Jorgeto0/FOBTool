# Hardware Documentation

This directory provides a concise description of the purpose of each schematic sheet in the FOBtool Hardware project.

| Schematic sheet | Purpose |
| --- | --- |
| [Power](POWER.md) | Manages the battery and external power inputs, charging, power monitoring, and the regulated supply rails used by the system. |
| [Main Controller](MAIN_CONTROLLER.md) | Contains the ESP32-S3 main controller, its essential support circuitry, and the control and communication interfaces to the other hardware subsystems. |

The complete schematic hierarchy is opened through [`FOBtool_HW.kicad_pro`](../FOBtool_HW.kicad_pro).
