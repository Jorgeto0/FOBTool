# Main Controller Sheet

**KiCad source:** [`MAIN_CONTROLLER_sch.kicad_sch`](../MAIN_CONTROLLER_sch.kicad_sch)

The Main Controller sheet contains the ESP32-S3 main processor and its essential power, enable, boot, and communication support circuitry. Its purpose is to provide the primary processing and control hub for the FOBtool hardware and to connect the processor to the radio, positioning, display, storage, user-interface, and secondary-controller subsystems.

Signal names on this sheet are defined from the main-controller perspective so communication interfaces remain consistent throughout the schematic hierarchy.
